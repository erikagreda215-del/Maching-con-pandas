# Práctica Pandas · Matching alumnos y notas

## Cómo ejecutarlo
1. `python -m pip install -r requirements.txt`
2. `python main.py`
3. Opción 1: informes CSV y JSON. Opción 2: gráfico. Opción 0: salir.

## Sobre el gráfico
Solo 2 alumnos tienen las tres notas válidas, así que las medias (8,00; 8,50 y 9,50) no representan a toda la clase.
La Actividad 3 tiene la media más alta y la Actividad 1 la más baja.
